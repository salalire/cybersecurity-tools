# 💻 Cybersecurity Command-Line Tools

A quick reference for useful command-line tools used in cybersecurity, especially for **DNS, domain, and network reconnaissance**.

The goal is to understand **what each tool is used for** and quickly check the basic syntax when needed.

| Tool | Description | Basic Example |
|---|---|---|
| **dig** | Query DNS records and obtain detailed DNS information. | `dig example.com` |
| **nslookup** | Query DNS records and resolve domain names and IP addresses. | `nslookup example.com` |
| **whois** | Retrieve registration and ownership information about domains and IP addresses. | `whois example.com` |

## 🧠 Quick Reference

- **`dig`** → Detailed DNS queries
- **`nslookup`** → Simple DNS lookups
- **`whois`** → Domain/IP registration information

> ⚠️ Use reconnaissance tools responsibly and only against systems you are authorized to investigate.
